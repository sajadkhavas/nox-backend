# NOX — ثبت هویت محلی

Branch: `design/nox-foundation-20261027`

اجرای صریح، فقط روی دیتابیس محلی nox:

```powershell
php artisan config:clear
php artisan db:seed --class=NoxBrandFoundationSeeder
```

همراه فرانت هم‌نام در مخزن nox استفاده شود. seeder در DatabaseSeeder یا migration ثبت نشده است.

قبل از اجرا، پشتیبان تنظیمات و صفحات در storage/app/private/nox-onboarding نوشته می‌شود. این فایل‌ها خصوصی و محلی هستند؛ آن‌ها را در Git قرار ندهید.

مشخصات برند، تماس، اطلاعیه‌ها، متن‌های عمومی و سه صفحه درباره، تماس و ارسال/تعویض بر اساس پاسخ‌های صاحب NOX تنظیم می‌شوند. ساختار سکشن‌ها عوض نمی‌شود؛ فقط ارجاع به عکس فروشگاه/محصول امضای LBB پاک می‌شود.

قیمت و موجودی ساخته نمی‌شود، داده شخصی LBB منتقل نمی‌شود و پرداخت یا سرویس ارسال فعال نمی‌شود. شرایط نهایی تعویض و روش پرداخت به تأیید تکمیلی نیاز دارند.

فیلدهای secondaryPhone و telegramChannel و telegramContact افزونه‌های JSON اطلاعات عمومی‌اند. نسخه فعلی فرم قدیمی SiteSettings ممکن است هنگام ذخیره مجدد contact.public فیلدهای ناشناخته را حذف کند؛ پس پس از هر ویرایش پنل، bootstrap را بررسی کنید. این مرحله API یا ساختار دیتابیس را عوض نمی‌کند.

اعتبارسنجی: syntax PHP با parser 8.3 پاس شد. اجرای seeder و تست پایگاه داده در این محیط انجام نشده و باید روی نسخه محلی کاربر تأیید شود.

Exact NEXT: دریافت شاخه فرانت و بک‌اند، اجرای seeder، تأیید پاسخ bootstrap و صفحات تماس/درباره، سپس ادامه طراحی سکشن‌ها.
